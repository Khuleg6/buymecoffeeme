## Prisma Next

Prisma Next setup is scaffolded in:

- `src/prisma/contract.ts`
- `prisma-next.config.ts`
- `src/prisma/db.ts`
- `src/prisma/users.ts`
- `src/prisma/seed.ts`

Database helper scripts are added to `package.json`:

- `bun run contract:emit` - emit contract artifacts after contract changes
- `bun run db:init` - initialize database state manually
- `bun run db:update` - update database state manually
- `bun run migration:plan` - create a migration plan
- `bun run migrate` - apply a planned migration
- `bun run db:seed` - insert sample users manually

For provider-specific Prisma Next reference docs, see `prisma-next.md`. Prisma Next skills live in the upstream `skills/` directory: https://github.com/prisma/prisma-next/tree/main/skills.

Node-based Prisma Next projects expect Node.js 24 LTS or newer.

Run the migration and seed scripts first, then `bun run dev` runs a small write/read round trip from `src/index.ts`.
